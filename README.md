## 🐛 Reportar Bugs ou Sugestões

Encontrou algum problema ou comportamento inesperado?
Abra um issue na aba [Issues](https://github.com/rolsite/premiumrelay-releases/issues/new) com:
1. Seu sistema operacional e versão (ex: Windows 11 23H2 ou Ubuntu 24.04).
2. Jogo testado e servidor/região.
3. Descrição do ocorrido e logs (se aplicável).
